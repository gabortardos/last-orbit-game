# Test Strategy

## Design validation

- Scripted rule-resolution examples
- Open-hand walkthroughs
- Closed-hand human playtests
- Player-count-specific testing
- Module-by-module A/B tests
- Measured fun, clarity, tension, agency, humour, and replay interest

## Future automated validation

- Unit tests for every effect
- State-machine transition tests
- Property tests for deck/card conservation and legal state
- Seeded simulation for probability and pacing
- Replay determinism tests
- Multiplayer synchronization and reconnect tests
- Invalid/malicious action rejection
- Responsive interface tests
- Accessibility checks
- Visual regression and performance tests

## Principle

Mathematical balance cannot prove that the game is fun. Human testing remains a release gate.
