## Confirmed current direction

- Working title: Last Orbit.
- Cool/cinematic visual centre with character-driven comedy.
- Multiple natural, technological, temporal, biological, and absurd Crisis identities.
- Strange cosmic life is allowed.
- Base play: 2–5 players; primary social target 3–5.
- Initial match target: 10–15 minutes.
- Disabled/towed/impounded ships rather than destroyed planetary populations.
- Five support cards plus one Emergency Reroute provisionally start each hand.
- Player-count-minus-one Crisis cards.
- Maximum two Commands per normal turn in the first test.
- Crisis identities share one effect in v0.1.
- No faction powers or Reactor Charge in the first core test.

## Current design question

Determine whether Rules v0.1 is understandable and fun in actual play, especially whether two Commands, future Flight Pressure, bounded reactions, and Crisis Reroute create agency without slowing the game.
