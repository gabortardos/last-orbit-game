# Architecture

Status: boundaries defined; technology stack undecided.

## Required separation

1. Deterministic rules engine
2. Authoritative multiplayer service
3. Data-driven content
4. Responsive user interface
5. Presentation/animation world

## Required qualities

- Seeded randomness
- Validated state transitions
- Event log and deterministic replay
- Save/reconnect support
- Untrusted network clients
- Stable card/effect/faction identifiers
- Automated interaction tests
- Desktop and mobile support
- Optional presentation adapters

## Explicitly undecided

- Framework and language
- Hosting and database
- Realtime transport
- 2D/3D technology
- Authentication
- Matchmaking
- Solar System Explorer component reuse

Technology selection occurs after the rules prototype and digital interaction requirements are clearer.
