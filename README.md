# Last Orbit

**Last Orbit** is an original browser-first online multiplayer game in development. Players command flagships from rival planetary civilizations, manipulate a shared interplanetary route, redirect escalating space crises, sabotage competitors, and try to remain the last operational ship.

The intended experience is fast, social, cinematic, funny, and readable for non-gamers. Early text/card prototypes exist to validate the rules before expensive illustration, animation, networking, or 3D work begins.

## Current status

Pre-production design. Phase 1 and Phase 2A are complete as first passes. The next milestone is exact **Rules v0.1**, player-count deck recipes, and a text-only card catalogue.

No application code or deployment exists yet.

## Product direction

- Browser-accessible online multiplayer
- 2–5 players, with 3–5 as the primary social experience
- Approximately 10–15 minutes per match initially
- Planetary civilizations, captains, flagships, and multiple Crisis identities
- Cool cinematic presentation with character-driven comedy
- Strong graphics and animation after gameplay validation
- Desktop and mobile support
- Separate deterministic rules, multiplayer, content, interface, and presentation layers

## Project boundaries

Last Orbit is thematically related to Gábor's Solar System Explorer but is a separate project and repository. Reuse of selected Explorer technology will be evaluated later; no reuse is assumed or approved yet.
